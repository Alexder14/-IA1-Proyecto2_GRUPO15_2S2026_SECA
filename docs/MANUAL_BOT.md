# Manual de usuario del bot de Telegram

Los 12 comandos obligatorios. Cada uno que falte o falle descuenta 5%.

| Comando          | Qué hace                                                      |
|------------------|---------------------------------------------------------------|
| `/status`        | CPU, RAM y estado de los servicios de la Raspberry Pi         |
| `/iniciar`       | Inicia el reconocimiento e interacción                        |
| `/apagar`        | Detiene el reconocimiento o apaga el servicio controladamente |
| `/history`       | Historial de gestos: fecha, confianza y acción ejecutada      |
| `/gestures`      | Lista los gestos registrados                                  |
| `/addGesture`    | Registra/entrena una nueva seña                               |
| `/deleteGesture` | Elimina o deshabilita una seña                                |
| `/actions`       | Muestra las acciones disponibles                              |
| `/addAction`     | Crea una acción ejecutable por el agente                      |
| `/linkAction`    | Asocia un gesto con una acción                                |
| `/sendMessage`   | Configura un mensaje como respuesta a determinado gesto       |
| `/rpa`           | Consulta los procesos RPA disponibles                         |
| `/logs`          | Últimos eventos, errores y acciones ejecutadas                |
